# 电平转换降本评估

2026-11-07；需求基线为 [requirements.md](requirements.md)。结论：本轮保留 U701～U704 的型号、封装和连接，只更新采购标识与价格。优先候选的芯片费用确实更低，但未通过 1.8 V／40 MHz 的最坏时序审查；现用 LXC 方案同样尚未闭合此时序。保留是避免引入未验证变更，不代表现方案已达标，也没有降低 40 MHz 目标。

本文件区分数据手册分析、价格快照、软件检查和待实测项。没有进行实板波形、吞吐或漏电测试。

## 功能和通道数量

主控侧 VCCA=P3V3，目标信号侧 VCCB=VIO_LOCAL，电平范围 1.8～3.3 V。转换器没有 I²C 地址或配置寄存器；DIR 只选方向，目标电平由 VIO_LOCAL 决定。FSA2466 只负责通断，不能代替电平转换。VIO 由 USB 辅助域供电，不从 DUT 或外部电流测量路径取电。

## 候选的引脚、方向与封装

优先候选为一颗 SN74LVC8T245PWR 加四颗 SN74LVC1T45DBVR。PW 是 TSSOP-24，DBV 是 SOT-23-6；上游 DCK 是 SC70-6，不能混用封装价格或 land。以下为厂家顶视物理脚号审查，候选尚未进入真实工程库或原理图。

|---|---|---|
|LVC8T245PWR|1 VCCA；2 DIR；3～10 A1～A8；11/12/13 GND；14～21 B8～B1；22 /OE；23/24 VCCB|1=P3V3，2=P3V3，地脚接地，/OE=XLAT_OEn，23/24=VIO_LOCAL；A→B 固定输出|

LVC8 PW 的功能脚号与当前 LXC8 PW 经两份顶视图逐脚比对一致；仍不能据此推导时序或上电兼容。LVC1 DBV 与原 LXC2 DCU 的脚数、尺寸和控制分组不同，需要重新放置和布线，不能直接修改 Value。LVC8 有独立 /OE；LVC1 **没有 /OE**。

每颗两个电源脚附近分别放置 100 nF；不能用一颗去耦代替两个供电域的局部去耦。所有去耦仍在夹具辅助供电域。

## 1.8 V 最坏时序

依据 TI 原厂数据手册：

- [SN74LVC8T245](https://www.ti.com/lit/ds/symlink/sn74lvc8t245.pdf)，SCES584D，May 2026，p4 脚号、p11 §5.9、p12 测试负载图。
- [SN74LVC1T45](https://www.ti.com/lit/ds/symlink/sn74lvc1t45.pdf)，SCES515N，June 2024，p3 脚号、p8 §5.8、p12 测试图及 Enable Times 计算说明。
- [SN74LXC8T245-Q1](https://www.ti.com/lit/ds/symlink/sn74lxc8t245-q1.pdf)，SCES920B，March 2023，p13。
- [SN74LXC2T45](https://www.ti.com/lit/ds/symlink/sn74lxc2t45.pdf)，SCES938B，May 2022，p14。

LVC 表为 VCCA=3.3±0.3 V、VCCB=1.8±0.15 V、推荐工作温度范围和数据手册规定负载；不是 25°C 典型数值。LXC 下表采用 −40～85°C 列，125°C 列更慢。没有把产品首页的 Mbps 换算成 SWD 频率。

|通路|最大延迟 ns|影响|
|---|---:|---|
|LVC8 A→B|21.2|固定输出 TCK 的最坏传播延迟|
|LVC1 A→B|15.5（低→高）；12.6（高→低）|SWDIO 写出或全单路方案的时钟|
|LVC1 B→A|8.3 / 7.1|SWDIO、TDO 读回|
|LVC1 DIR→B 关闭|20.5|主控放弃总线后，目标开始驱动前需要保证释放|
|LVC1 DIR→A 开启|27.6|读方向建立；该开启时间为手册计算值，不能忽略|
|LVC1 DIR→B 开启|21.1|恢复写方向|
|LVC8 /OE→B 关闭 / 开启|29 / 27.7|只用于分组启停，不是在每个数据位切 OE|
|现用 LXC8 A→B|15（125°C 为 16）|当前时钟路径|
|现用 LXC2 B→A|16（125°C 为 17）|当前返回路径|
|现用 LXC2 A→B|17（125°C 为 18）|把时钟挪到空余双路并不能直接解决延迟|
|现用 LXC2 DIR→A 开启|37（125°C 为 39）|当前换向本身也需要时序验证|

40 MHz 周期为 25 ns，半周期为 12.5 ns。以目标在下降沿更新、主控下一上升沿采样的常见读时序作保守筛选：

```
t_clock_out + t_target_clock_to_out + t_return + t_setup
+ FSA/RC/线缆延迟 + 时钟占空比/抖动裕量 < 12.5 ns
```

混合候选仅转换器的最坏往返和已为 21.2+8.3=29.5 ns；全单路为 15.5+8.3=23.8 ns。前者连一整周期都超出，后者即使假设一整周期采样也仅余 1.2 ns，尚未计目标、FSA、线缆和建立时间。DIR→A 的 27.6 ns 也大于一周期，不能假设一个 turnaround 周期足够。

现有 LXC 的相同保守和为 15+16=31 ns，同样未通过。以上是**最坏界限无法证明通过**，不是宣称所有实物在 40 MHz 必然失败。改变采样相位、延后读取或调整 turnaround 可能改变预算，但取决于 HPM SPI/GPIO/DMA 实现、目标 SWD/JTAG 时序与协议允许条件；目前没有实现和验证，不能据此批准换料或宣称达标。目标芯片型号、负载、温度范围和采样相位必须进入后续验收记录。

## FSA、串阻、负载与上下电

FSA 在通信期间持续导通；其开合时间不等于每位的传播时间。应将导通电阻、器件电容、连接器、走线和线缆电容计入每个方向的边沿与建立时间，不能只引用带宽。短线 ≤10 cm 只是初版假设，没有线缆实测数据。

实际网表中 R1/R2=22 Ω，分别连接 SWD_MOSI/SWD_MISO 与 SWD_MCU，并非 USB 串阻；读写两条 MCU 分支都有电阻和引脚负载。TCK/TDI/TDO 不具有统一的 22 Ω 串阻。示例 RC 估算 `t10–90≈2.2 R C`：仅 22 Ω、总负载 30 pF 已约 1.45 ns，60 pF 约 2.90 ns；这是示例负载，不是本板实测值，尚未含驱动输出电阻和 FSA Ron。应实测双串口并发时的串扰、过冲和阈值穿越，必要时再定串阻/走线，不能无依据增加电容“滤波”。

LVC 系列支持 Ioff 和电源为 GND 时的隔离，但这些条件不等于悬浮/斜坡中的 VIO，也不等于整板 100 nA。LVC1 输入级始终工作，无 OE：

1. 固定返回通道 DIR 硬接 GND；动态 SWD_DIR 在复位期间需要明确拉向安全方向。两侧驱动必须按 disable/enable 最大值交接，不能由两个驱动短时对打来“加快”。
2. FSA 断开后，转换器侧接收输入会悬空；需在 **FSA 的夹具侧** 设置弱偏置，处理未用输入及 UART 空闲高。该额外器件、漏电、输入慢边沿功耗没有纳入下面的简化成本表。
3. OE 上电高、SIG_ARM 默认禁能以及 FSA 各组默认断开需要硬件与固件共同保持；无 OE 单路不能代替 FSA。
4. LVC1 的 Ioff 最大值达到 µA 量级，并不满足夹具附加电流指标；目标侧低功耗隔离仍由 FSA 和继电器链路承担。FSA 在 USB 掉电时并无完整掉电隔离保证，目标外部供电时反灌风险仍未解决。

参考 [TI LVC1 数据手册](https://www.ti.com/lit/ds/symlink/sn74lvc1t45.pdf)的 Ioff、VCC isolation、未用输入章节及 [onsemi FSA2466](https://www.onsemi.com/pdf/datasheet/fsa2466-d.pdf)。14 个 FSA 使用通道在 25°C 最大漏电之和已达 140 nA，尚不含 PCB、检测和其他支路；维持 ≤100 nA 目标，但不能写成保证。

## VIO 与测量锁

改变目标电平必须先停止调试/发送、断开所有信号组和复位组，禁能转换器；在允许检测的显式流程中核对目标 Vref，再调 VIO。外部 DUT 供电不等于 VIO 已匹配；DUT 可以 5 V 供电而接口仍是 1.8 V/3.3 V，数字口仍不接受 5 V。

U504 MCP4726＋U502 TLV758 保留调压，VIO 与 DUT 供电分别控制。写 DAC 并读回配置只能证明数字命令，不证明模拟电压正确；当前没有独立 VIO ADC，电压精度、稳定时间和过冲需实测定界。在 MEASURE 锁定状态，调压请求可拒绝或保持断开后执行，完成也不得自动解除锁；目标 Vref 检测同样不能暗中闭合 K901。串口打开、DTR/RTS 和 DAP 命令均无隐式解锁权限，恢复连接须独立明确命令。

以上是控制要求；独立板型固件和真实 HID 协议尚未实现，主机工具不能宣称已有这套控制能力。
