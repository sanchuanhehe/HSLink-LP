# ARM20 接口与配套排线

2026-11-07，按用户要求以带键传统 ARM 20 针替换 J801，删除 J802；目标供电继续使用独立 J602，不经调试排线。

## 定义与隔离

采用 **2×10、2.54 mm** 的传统 ARM JTAG20 接口，不是 1.27 mm Cortex Debug+ETM20。标准定义参考 [Arm CoreSight IHI0029D D3.2](https://documentation-service.arm.com/static/5f9009d5f86e16515cdc0417)，探针侧供电/保留脚兼容边界参考 [SEGGER 20-pin 接口](https://www.segger.com/products/debug-probes/j-link/technology/interface-description/)。本工程没有实现 RTCK 自适应时钟、DBGRQ/DBGACK。

- 1脚 VTref → DUT_VREF → U901.COM(5)→NO(6) → VREF_SENSE_IN → 原分压/ADC。不接 P3V3、VIO_LOCAL、DUT_OUT 或任何供电输出；NC(4)悬空，开关前没有分压/保护支路；检测仍由 SENSE_ON 控制，在 MEASURE 状态断开。VTref 是目标逻辑电压参考，1.8～3.3 V；独立DUT电源可能更高，不能将5V板端电源误当3.3V逻辑参考。
- 3脚 nTRST → DUT_NTRST → U804的3/4脚开关通道 → F_NTRST → Q702开漏；15脚 nRESET → DUT_NRST → U804的15/1脚 → F_NRST → Q701开漏。两个复位不短接，不新增目标侧上拉；低电平由开漏拉低，高电平由目标侧形成。RESET_ON断开覆盖保留。
- 5/7/9/13脚分别为TDI、TMS/SWDIO、TCK/SWCLK、TDO/SWO，仍通过U801的原FSA通道；DEBUG_ON断开覆盖保留。
- 2脚NC，不与1脚短接，也不接USB/VIO/目标电源。11脚RTCK未实现，保持NC而非接地，避免对目标输出形成负载。17脚DBGRQ与19脚DBGACK/厂商可选供电脚均NC，无下拉、ESD或供电支路。
- 4、6、8、10、12、14、16、18、20共九个GND脚接现有共地；不能用这些地脚传递独立低侧电流测量而忽略USB共地旁路。保持项目原来的共地假设。
- 不新增UART或复位控制命令。调压、打开CDC、DTR/RTS、DAP均不得解除测量锁，真实控制协议/固件仍未实现。

## J801 型号与逐脚封装映射

采用 BOOMELE `2.54-2*10P简牛`，嘉立创 [C3405](https://www.jlc-smt.com/lcsc/detail/C3405.html)，黑色护套、中心防反插键槽、直插20针。厂家图 [BX2.54-2xNA，单页，未标修订日期](https://atta.szlcsc.com/upload/public/pdf/source/20220902/F4C4645E59EE38C0F12B225613E1076A.pdf)：N=10，外长33.02±0.3、宽8.9±0.2、内长30.72±0.3、内宽6.35±0.2、键槽4.5±0.1、针距/行距2.54、方针0.64、焊脚3.0±0.2、建议孔1.0 mm。

## 配套排线

配件 `CBL801`：XFCN `CL2542320200BC10E`，嘉立创 [C7496759](https://www.jlc-smt.com/lcsc/detail/C7496759.html)。两端均为2.54 mm、2×10P三件式IDC母头，带极化凸键和折返压线卡扣；20芯UL2651/28AWG、导体间距1.27 mm。**母头接点间距2.54 mm与线芯间距1.27 mm不能混为一谈。** 配件单独计入 `hardware/bom/accessories.csv`，不是板上焊接位号或SMT换料项目。

[厂家图，2023-07-05，单页](https://atta.szlcsc.com/upload/public/pdf/source/20240110/976CA9EBFC80C4582DD9358FE4D13126.pdf)列出2个IDC插头和2个压线卡扣；标题“L=200mm不含插头”指线段长度不计连接器，不能解释为不带接头。尺寸200±10 mm，两端同向，红边指1号导体，P1的1～20逐根直通P2同号，无交叉/并接。图中的母座插合面1在右上、2在左上；与板端公针顶视相对插合后同号接触，防反插凸键进入J801中心槽。

规格资料接受其针数、直通关系及名义IDC插合形式；跨厂家键槽配合公差、插拔力、接触可靠性须来料实物确认。逐根1↔1至20↔20导通测试，并检查任意不同针间无短路，再接目标板。

这条现货排线为20 cm，长于此前≤10 cm的默认试验假设。保持40 MHz目标，必须增加20 cm配套排线的SWD读回/换向、JTAG、眼图/过冲/串扰实测；未证明20 cm在40 MHz下可用，不将其供货状态当时序保证。

**低功耗采购门槛：** 排线手册只承诺绝缘电阻≥5 MΩ。以3.3 V/5 MΩ作保守示例为0.66 µA，已高于整板0.14 µA目标，且实际多导体泄漏不由这一个比值完整描述。因此这条线属于打样配套、尚未通过低漏电验收，不作合格量产线束放行。必须在25±5°C、记录湿度/清洁度下，比对排线接入与物理拔线的附加电流；覆盖VTref及目标高电平到全部接地芯线，确认总夹具≤0.14 µA。若不满足，需更高绝缘规格的短线或定制线束，并重新核价，不能降低漏电要求。J801手册绝缘≥1000 MΩ同样不等于整板保证。
