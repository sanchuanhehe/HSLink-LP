# 使用边界与电气余量

2026-11-07。VIO修改基线Git `cad895d`，R42落地基线Git `4a619c1`，以[需求基线](requirements.md)为准。VIO反馈电阻及LDO输入已修改，用户已确认低成本、逐板外部校准与±1%目标。资料分析、文件检查和实板验收分开记录；计算不构成硬件保证。VIO证据位于已忽略的 `hardware/design/reports/margins-2026-11-07/`，R42落地检查位于 `hardware/design/reports/r42-2026-11-07/`，摘要和源文件哈希见[validation.json](../hardware/validation.json)。

## 已确认的边界

- 整夹具附加电流目标为 **≤140 nA（0.14 µA），20～30°C**。保持目标供电、夹具正常上电、全部信号与检测支路断开，与物理断开相同信号连接作差；目标端电压保持一致。不是FSA单独预算，不是实测结果，也未同意700 nA或仅25°C。
- 首版不支持调试器USB掉电而目标仍供电时的FSA保护。目标信号连接期间须保持USB供电；不单为此工况加保护或换FSA。关闭FSA控制脚并不能证明掉电保护；移除USB前应先断开目标信号连接。启动/复位默认关闭、不得主动放电和测量锁约束仍保留。
- 内置1.8～5.0V、最高1A和外部1.8～5.5V、最高2A保持；VIO设置范围保持1.8～3.3V。U901保留Vref检测，DUT_OUT回读、K901/K902均不恢复。

该表测试端电压是0.3V或VCC−0.3V等组合，并非所有真实逻辑电平的独立保证。这里实际VCC−0.3V约3.246～3.354V，目标端0/1.8/3.3V、A端高低/浮置和VIO关闭都须逐项核对，不能把“模拟范围覆盖”推导为“漏电上限已覆盖每个状态”。

[DG2012E原厂手册](https://www.vishay.com/docs/75834/dg2012e.pdf)的5V表在规定测试点下给出25°C 5nA、全温20nA等级；现设计对COM/未选NO暂留40nA，只是工程预留，不是厂家对实际COM=1.8～3.3V且NC浮置状态的合计保证。与FSA筛选值相加为180/740nA，仍未含连接器、线束、PCB；**这不是新的验收阈值，也不是实测值**。USB=0时U901单器件最大1µA特性另记，不代表整板/FSA具有掉电保护。

样机必须覆盖20/25/30°C、1.8/2.5/3.3V目标域、目标输出高/低/高阻、复位高低、夹具A端默认及允许状态、USB/P3V6容差；分别测单支路与完整夹具，再与物理拔线比较。记录湿度、清洁工艺、样板/线束批次、仪器量程与不确定度。若失败，重新分配支路预算/改器件或线束后复测；本轮未获准进一步放宽目标。

### 外部校准与安全过程（设计约束，尚未实现）

1. K601按测试目的保持隔离，所有FSA、复位和U901断开；目标不参与VIO校准负载。探测C44.1/VIO_LOCAL与C44.2/GND，外部仪器记录不确定度。确认样板序列号、BOM和软件版本。
