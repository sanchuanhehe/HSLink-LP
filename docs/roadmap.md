# 实施阶段

## P0：关键电路验证

- 冻结完整引脚表及功率、漏电预算。
- 验证 ADG4612＋电平转换的高速路径与低漏电。
- 验证供电测量仪经过受控开关后的误差、压降与温升。
- 确认电源来源选择方式和外部仪器型号。

完成条件：关键指标有实测数据，候选器件转为已验证选型。

## P1：原理图与 PCB

- 以锁定的 1.2.0 参考工程建立新 KiCad 工程。
- 完成双串口、电源、开关组、检测及恢复接口。
- 完成 ERC/DRC、布局审查和可测性审查，输出 BOM、Gerber、贴片坐标。

## P2：固件

- 新增独立板型与硬件身份。
- 双 CDC、DMA、HID 控制及统一状态机。
- Bootloader / 应用均保证默认关闭，保留 ISP / JTAG 恢复入口。
- 完成编译、协议测试与硬件联调。

## P3：Mac 工具

- 实现 HID 传输、设备身份识别与控制 API。
- 提供 CLI、Python 库、测试流程及时间戳记录。
- 根据实际仪器型号实现适配器。

## P4：验收

执行 docs/validation.md，记录未通过项及使用边界。达到指标后再标记为可交付硬件。
