# 总体架构

## 电源路径

USB 供电 → 内置可调电源 → 来源选择 → 受控电源开关 → 目标板。

外部电源／供电测量仪 → 来源选择 → 同一受控电源开关 → 目标板。

来源选择按用户选择采用机械开关；准确型号的至少 2 A DC 额定值、先断后接动作及封装待签核。USB 为 HPM5301、电平转换、开关驱动等辅助电路供电。不得把这些辅助耗电接到外部仪器被测路径。

内置电源选型为 TPS63810YFFR（启动隔离/编程顺序见 procurement-completion.md），范围限制为 1.8～5.0 V；增加内部支路硬件过流保护。USB-C CC 检测器用于确定可用输入电流，功率不足时限制输出。

输出开关为 K601 HFD2/005-S：COM/4接DUT_OUT、NO/8接SOURCE_POWER，NC/6经R57=1k和Q902低边NMOS接地。Q601驱动线圈，从USB侧供电；Q902有R62栅源下拉，默认关闭。验证触点压降、2 A 温升、浪涌、微小电流接触可靠性及释放时间。外部输入的电流限制由外部仪器承担。详见 [降本设计](cost-down.md)。

## 信号路径

HPM5301 → 方向可控电平转换 → 模拟开关组 → 目标接口。

目标侧 VIO 由受输入保护的 USB_5V 经 TLV75801 + MCP4726 生成，并按目标Vref配置，不从目标 Vref 直接取电。首版数字信号限制为 1.8～3.3 V；FSA2466 使用 USB 侧 3.6 V 电源。外部目标电源仍可到5.5V；本板只检测1.8～3.3V的Vref，由USB_5V供电的U901在完整68k/68k分压之前隔离。DUT_OUT电压回读取消，不表示目标供电范围缩小或数字端口支持5V。

4 颗 FSA2466 提供 16 个数字通道，使用其中 14 路；U901负责Vref检测隔离；放电复用K601常闭触点和Q902，K901/Q901/D901和此前K902/D902均已删除，实际仅K601一颗继电器，见[检测/放电优化](sense-discharge.md)：

| 分组 | 通道 |
| --- | --- |
| DEBUG | SWDIO/TMS、SWCLK/TCK、TDI、TDO |
| RESET | nRESET、nTRST |
| UART_A | TX、RX、DTR、RTS |
| UART_B | TX、RX、DTR、RTS |
| SENSE | 仅Vref；无DUT_OUT实测电压 |
| DISCHARGE | 目标电源放电支路 |
| RESERVED | FSA 两路及继电器未用触点；保持未连接 |

FSA2466 参考 Nordic nRF54L15 DK 的同款选型；40 MHz 波形及整板漏电验证通过后再冻结 BOM。其开合时间不是数据位速率，开关在传输期间保持导通。数据表 25°C 关断漏电最大值按每路 10 nA 预算，仅 14 路已达 140 nA，尚未计入检测开关、PCB 和连接器，因此当前候选不能保证整板 140 nA。不得用典型值替代最坏情况。覆盖20～30°C的全温上限为50 nA/路，14路700 nA仅为保守筛选值，非实测。FSA2466没有掉电隔离保证；用户已接受首版不支持USB掉电而目标仍供电的FSA保护工况，连接目标信号期间须保持USB供电，不为此单独增加保护或换FSA。

Vref分压必须整条可断开。现用68k＋68k在3.3V下约消耗24.26µA，仅显式检测时允许；DUT_OUT分压已删除。ESD、上拉、LED、测试点及未使用接口也必须审计。

电平转换器的逐颗用途和成本见 [电平转换说明](level-translation.md)。四个 I2C 从设备共用 3.3 V 总线，地址为 0x68（WUSB3801）/ 0x60 / 0x74 / 0x75；已删除原同地址电源方案所需的多路器，具体初始化见 [降本设计](cost-down.md)。

## 引脚和控制资源

- UART_A：UART2，PA08 / PA09，保留原有 DTR/RTS。
- UART_B：UART0，PA00 / PA01，停用该 UART 的日志输出，保留 ISP 恢复入口。
- 新增 DTR/RTS、分组开关等慢速控制使用 I²C GPIO 扩展器。
- 全局信号禁能及电源总使能由 MCU 直接控制，并硬件默认关闭。
- 完整引脚表尚未冻结，必须检查 HPM 自身 JTAG、BOOT 采样、USB、SPI 加速及 DMA 冲突。

## 固件状态

| 状态 | 目标供电 | 信号 | 检测 |
| --- | --- | --- | --- |
| OFF | 关 | 全断开 | 关 |
| ACTIVE | 开 | 按组连接 | 仅显式检测许可时开 |
| MEASURE | 保持开 | 全断开 | 关 |
| FAULT | 关 | 全断开 | 关；故障诊断不得自动接通 |

上电、复位和 Bootloader 默认 OFF，不自动恢复输出。MEASURE 的优先级高于 Vref 自动检测、串口打开、DTR/RTS 与 DAP 请求。USB 掉电和复位由硬件释放继电器，输出在触点释放后关闭，故障解除后须显式重新连接。

进入测量前停止 DAP 事务、等待 UART 发送完成；设置有界超时，超时报错并断开。断开期间不积压或重放 UART 数据。显式退出MEASURE后恢复时重新检查目标逻辑Vref（不是DUT_OUT电压）、先写 DAC 再使能 VIO，等待稳定后连接端口。显式放电先关闭供电并等待K601释放/抖动稳定，再开Q902；恢复先关Q902再吸合K601。50ms是待实测切换初值，不是放电完成时间。保持供电时NC机械隔离放电支路；关闭供电但不放电时仅MOS关断，仍有泄漏。互锁真值表和理想接点图不证明转换瞬态。

## USB 与主机

USB 组合设备：CMSIS-DAP＋两路 CDC＋厂商 HID。CDC 的描述符、接口编号、端点、DMA 和缓冲区必须分别分配，核对 USB HS/FS 两套描述符。

HID 协议需要覆盖能力查询、状态查询、内置电压、供电开关、端口连接、测量切换及断电重启。使用版本与请求标识，区分接收和完成；正式报文格式在固件与主机共同实现时冻结。

Mac 第一版提供 CLI＋Python 库，按序列号识别设备。当前 host 仅包含本地工程信息命令，没有 HID 通信实现。

## ARM20 目标接口

J801采用带防反插结构的2×10、2.54mm ARM20，J802删除。nTRST接3、nRESET接15，分别经原U804开关与独立开漏；调试四路经U801，VTref经U901 COM/NO。2/11/17/19留空、九个地脚接公共地；不通过调试排线给目标供电，J602仍独立。双UART与握手隔离不变。详见 [接口与排线](arm20-interface.md)。排线绝缘、20cm时序及正常上电断开漏电仍待实测，MEASURE锁和独立板型控制要求不变。

检测控制及不再提供的回读语义见 [控制接口约束](control-interface.md)。DUT_OUT掉压、输出实际电压和放电完成无法由本板ADC确认；需要外部仪器，当前仪器适配和真实协议未实现。

VIO反馈已改为10k/2.15k/15.4k，LDO输入改USB_5V；逐板外部校准、±1%为已确认目标，尚未实测。R42低成本候选与验证门槛见[余量说明](electrical-margins.md)，不把条件计算当量产保证。
