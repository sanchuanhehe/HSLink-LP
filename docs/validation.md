## 原理图文件检查

在工程根目录使用 KiCad 10 的命令行重新导出：

```bash
mkdir -p hardware/design/reports
kicad-cli sch erc --format json --exit-code-violations -o hardware/design/reports/erc.json hardware/design/HSLink-LP.kicad_sch
kicad-cli sch export netlist --format kicadxml -o hardware/design/reports/netlist.xml hardware/design/HSLink-LP.kicad_sch
kicad-cli sch export pdf -o hardware/design/reports/HSLink-LP.pdf hardware/design/HSLink-LP.kicad_sch
```

`reports/` 为可再生成输出，Git 忽略。每次电路修改后，核对实际 XML 网表与 `hardware/design/connectivity.json` 中的器件及引脚网络集合，同时检查未连接引脚、缺失封装，并逐页查看实际图面。验证通过后更新摘要和文件哈希；临时检查脚本不保留在工作区。`connectivity.json` 是设计基线，不能代替实际导出网表。

版面修改也必须核对网表。对每个标签，检查文字是否被导线、引脚或符号边框穿过，移动后是否仍有明确接点；电源汇线应避开引脚编号。对自定义符号，核对引脚线内端与边框、脚名位置，并确认脚号、电气类型和外部连接端坐标未被排版操作改动。分别查看默认字体和实际阅读字体的导出图；过滤空白字符后的文本包围盒检测只能作为辅助。

最新降本检查通过标准 MCP 执行；服务调用 KiCad CLI 运行 ERC，原始 MCP 响应保存在 `reports/sense-discharge-2026-11-07/erc-mcp.json`，其余证据见 `hardware/validation.json`。上面的命令可重新生成完整 CLI ERC JSON。

## 硬件验收

| 项目 | 方法与通过条件 |
| --- | --- |
| 40 MHz | 在支持该频率的目标或测试夹具上检查实际时钟、双向时序、波形及错误；记录 1.8/3.3 V 信号电平、线长、负载和探头 |

| 内置供电 | 1.8/3.3/5.0 V 下检查空载、负载、瞬态、纹波、温升、过流保护及 USB 输入电流预算 |

| 断开覆盖 | 逐项检查调试、复位、两路 UART、Vref、目标电压、放电、ESD 与备用接口 |

| 继电器 | 最小负载接触、1/2 A 压降温升、浪涌和寿命；示波器测含续流的释放/吸合时间，确认供电与放电接点无重叠 |
| VIO | DAC 启动值、通信故障、默认 EN、1.8～3.3 V 精度/过冲及 100 mA 预算下热验证 |

## 前置验证

先制作“电平转换＋模拟开关”验证电路和电源路径验证电路，通过后再冻结整板原理图。

漏电测试使用可覆盖 0.1 µA 误差目标的仪器和接线。必须排除目标自身电压变化、USB 额外供电、低侧测量被共地旁路、接触污染等影响。

室温测量状态、掉电状态、电源关闭状态和高温状态分开记录。任何未达到的设计指标应明确标注，不静默降低验收目标。

## 报告字段

样板编号、硬件/固件版本、仪器型号及校准信息、温湿度、电源和信号电平、接线照片、测试步骤、原始数据路径、结果与限制。

本轮电感/CC/VIO 前级换料的资料分析见 [jlc-design-review.md](jlc-design-review.md)；电平转换尚未闭合的最坏时序与实测条件见 [level-translation.md](level-translation.md)。

上游采样/换向的源码依据与前置测试测点见 [upstream-swd-timing.md](upstream-swd-timing.md)。SWD 按整周期、JTAG TDO 按半周期分别检查；包含 HPM SPI 输入建立/保持时间。不得用段间等待、下载成功或 CPU 读 DATA 的时刻代替段内输入采样裕量。

本次 12 颗单路方案已加入 R713 默认接收及夹具侧偏置。重点新增实测：FSA 断开后返回输入稳定、MCU 启动与 SWD_DIR 默认状态无争用、无 OE 条件下 VIO 斜坡及恢复顺序。40 MHz 保持原验收目标，未实测项不得记作 PASS。

采购补齐后重点增加：TPS63810默认3.3V在K601断开期间的编程/欠压恢复、DRV散热EP、R38+R401反馈稳定性、替代续流二极管的释放时间。R42=1.15k的0.75～1.25A限流范围尚不能保证1A连续负载，须作为设计门槛处理。详见 [采购补齐设计说明](procurement-completion.md)。

ARM20新增来料与实板项目：逐根1↔1至20↔20导通/无异针短路，公母键槽与1脚方向实际插合；确认2/11/17/19不与任何供电或负载相连。检查第1针VTref及3/15复位在MEASURE中的断开。用20cm配套排线分别测试SWD/JTAG 40MHz和1.8/3.3V，包括换向读回、过冲/串扰；≤10cm短线仅作基准。排线手册绝缘≥5MΩ不满足整夹具100nA的保证条件，须覆盖目标高电平/VTref到地芯和其他芯线的泄漏；若实测失败，换高绝缘短线/定制线并重核价，不降低指标。

检测/放电优化新增验收：K601 COM/NO/NC实物导通核对；含D601的释放/转换抖动及Q902栅极波形，覆盖USB缓升缓降、拔电、复位和未初始化；未经请求不得主动放电。分别测MEASURE的NC隔离漏电、OFF时Q902关断漏电、负载电容放电时间/1k温升及外部持续供电情形。显式放电先断供电再等待、恢复先关MOS，核定等待值后替换50ms初值；不能拿继电器裸件3.5ms或理想逻辑真值表代替。K901/Q901/D901和DUT_OUT专属采样已删除；Vref在U901断开时完整分压不得加载目标；FSA140nA与线缆/PCB漏电预算问题仍保留。文件层面前轮16组稳定逻辑输入与6种理想接点状态已查，本轮复核16组互锁与32组SENSE稳定输入组合，均非瞬态/硬件PASS。见[优化说明](sense-discharge.md)。

Vref单通道新增验收：目标1.8/2.5/3.3V，USB正常供电容差、缓升缓降/瞬断/0V，20/25/30°C及扩展温度，记录U901 COM电流、USB反灌、ADC端电压与采样误差。浮置NC保持不接，不在COM前增加未预算保护。ADC校准和开关接通后的稳定等待须用实测定界。MEASURE锁下读Vref应拒绝或返回带时间戳的旧值，不得自动接通。

DUT_OUT实测回读功能已取消：输出精度、负载掉压、放电结束和开关接点实际状态由外部仪器验证；固件计时到期、寄存器值或PG状态不得用作“已测得0V/目标电压”的证据。全部未实板验收。当前软件检查详见validation.json。
