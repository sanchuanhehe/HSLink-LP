## 结构与使用方式

底座固定 PCB 并提供防滑支撑，透明盖保护器件，同时允许观察状态和拆盖调试。优先采用通用紧固件、平板盖和可打印底座验证装配；透明盖可在 PC、PETG、亚克力等方案中按韧性、加工方式和成本再选，尚未选材或报价。

PCB 板框先服从接口、安装孔和插拔空间。原90×60mm只是布局假设；不能根据效果图直接定型。先用连接器厂家尺寸/STEP建立占位装配，计入配套插头、排线弯曲和手指拔插空间，再决定底座外形与盖板高度。模型精度取决于厂家资料，不把效果图当加工图。

建议的布局顺序（待机械/PCB联审）：

1. 使用者一侧放带防反插的ARM20、双UART及独立目标供电接口；不要把目标供电混入调试排线。
2. USB和外部电源入口尽量布置于另一侧。来源拨动开关保留清楚的内置/外部标识，避免排线遮挡或插拔时误碰。
3. 先放连接器、开关、安装孔，再围绕MCU、电平转换器、FSA安排最短调试信号路径。机械方便不能替代40MHz时序/信号完整性检查。
4. Vref入口、U901及断开后的高阻区域远离开关电源、线圈驱动、脏污易积聚处；螺柱/盖板不压线、不遮挡测试点。PCB清洁度和结构材料的表面漏电纳入140nA实测。
5. 为U501、电感、U503和VIO LDO留散热铜箔及测温/探测空间。底座和盖板不能妨碍这些检查；本轮完成简化尺寸模型的装配体积干涉检查；热与实物装配未验证。

## UX约束

界面必须分别显示“电源来源”“输出开关请求/控制状态”“信号连接/测量锁状态”。MEASURE时目标保持供电，信号和检测断开；不能把“断开信号”显示成“目标已断电”。

没有DUT_OUT或VIO电压ADC，显示的是设定值或校准预测值，不能显示为实际电压。无真实HID协议、无已实现测量锁固件，不以原型界面暗示功能已经完成。

新增实体MEASURE键和额外状态灯仍为建议，未修改原理图/BOM。透明盖与底座本身即可先围绕现有开关、接口及器件布局设计。
