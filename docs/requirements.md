# 需求基线

记录日期：2026-11-04。来源：本项目对话中用户已选择的方案。

## 已确认

| 项目 | 要求 |
| --- | --- |
| 基础 | HSLink Pro 1.2.0 / HPM5301 |
| 形态 | 重新设计整板 |
| 串口 | 两路独立 CDC，均有 TX/RX、DTR/RTS |
| 电平 | 首版 1.8～3.3 V；用户为降低成本选择参考 Nordic FSA2466 |
| 调试 | SWD/JTAG，40 MHz 为验收目标 |
| 内置供电 | 1.8～5.0 V，最高 1 A，可调压及开关 |
| 外部供电 | 1.8～5.5 V，最高 2 A，支持独立电源 |
| USB | 单 USB-C，供电不足时限制内置输出功率 |
| 测量 | 外部供电测量一体仪器；具体型号未指定 |
| 断开器件 | 信号优先参考 Nordic 同款 FSA2466；Vref/采样/放电另做电压与漏电审查 |
| 漏电目标 | 25±5°C 时，测量状态的夹具附加电流 ≤0.1 µA |
| 主机工具 | Mac 命令行工具＋Python 库 |
| 电源来源选择 | 板上手动切换；内置／外部两路均保留电脑控制输出通断 |
| 成本口径 | 人民币，10 套打样；元器件、PCB、贴装与其他费用分别列出 |

## 默认假设与待确认项

- 保留共地；本项目不构成电气隔离设备。
- 两路串口连接同一目标板，默认共用 Vref。多电压域需求尚未确认。
- 原理图中所有供电、检测、保护支路均需纳入漏电检查。
- 外部仪器型号、控制接口和负载瞬态条件仍需在仪器适配阶段确定。
- PCB 约 90×60 mm、四层、短线 ≤10 cm 是初版布局与验收假设。
- 双串口同时 3 Mbaud / 8N1 是建议的首版性能验收基线。
- 40 MHz 是目标，不是已实现能力；测试目标本身必须支持该时钟。

## 指标定义

“≤0.1 µA”指目标板保持供电、夹具正常上电、全部信号和检测支路断开时，相比物理拔掉相应信号连接的附加电流。比较时保持相同目标端电压，记录温度、湿度、仪器量程与测量不确定度。

电源关闭漏电、USB 掉电漏电以及高温漏电分别记录，不套用室温测量状态的指标。
