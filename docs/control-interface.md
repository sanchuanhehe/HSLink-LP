# 控制接口与电压语义约束

2026-11-07。此处是固件/主机共同实现前的设计约束，不是已实现报文协议。host仅本地info骨架，改版固件尚无板型，不新增虚构传输成功结果。

- 能力应明确 `dut_voltage_readback_supported=false`、`target_vref_sensing_supported=true`。实际报文格式、版本及操作码仍待共同冻结。
- `output_voltage_setpoint_v`仅表示内置电源要求值；寄存器回读仅说明数字配置，不是实测。外部来源的电压由外部仪器决定，不伪造对应本板设定值。
- `target_vref_measured_v`仅对应J801.1的1.8～3.3V逻辑参考，经U901/R53/R54/C61/U1.27采样；与DUT供电电压、VIO实际电压分别处理。应带有效标志、时间戳与状态，断开时返回不可用或标记过期的历史值。
- 不提供 `dut_voltage_measured_v` 数字。输出通断状态只可表示控制命令/时序阶段，本板无接点反馈，不能表示目标必然有电或已为0V。PG或I²C读回不能代替DUT电压。
- 不承诺基于DUT_ADC的输出确认、掉压检测、放电到阈值自动停止。保护仍有既有硬件限流/故障输入；电源实际值和放电完成需外部仪器，适配未实现。未接仪器时只能报告“放电定时结束、残余电压未知”，不得报告“放电完成已验证”。

默认上电、复位、FAULT：SIG_ARM_REQ/SENSE_REQ/所有信号REQ=0，R61及R36下拉SENSE_ON；U901.IN低→COM接浮置NC，NO分压断开。主控空闲U1.26配置为无上下拉高阻；不得重新命名ADC_VOUT并继续发送模拟数值。

MEASURE保持K601供电、Q902关闭、所有FSA与U901断开。串口打开、DTR/RTS、DAP、Vref读命令和调压均不能解除锁；需专用显式退出操作。连接流程：停止事务→保持隔离→显式允许Vref采样→等待稳定/ADC校准采样→设置独立VIO→按实测界限等待→核对方向→按组连接。不得从目标Vref供给VIO电源。

内置供电恢复：K601断开、Q902关闭→配置/回读TPS63810寄存器及状态→按验证后的稳定时间等待→显式接通K601。此过程不能由本板确认输出模拟电压正确。放电：显式请求→信号/检测REQ清零→POWER_REQ清零→等待释放及抖动稳定→只启用DISCH_REQ所需ARM→打开Q902→有界定时/取消/故障关闭。恢复先关MOS再吸合K601。50ms仅既有待测转换初值；不能当作残余电压验收。实际USB掉电、栅极和继电器动态仍待实测。
