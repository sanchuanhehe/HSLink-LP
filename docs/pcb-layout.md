# PCB 布局与布线约束

2026-11-13。当前一般 DRC 违规 0、未连接 50、原理图一致性错误 0，仍是布线检查点，不能投板。最新阶段见[控制与模拟布线](control-analog-routing.md)；以下保留布局基线和历史过程，各阶段数量只适用于对应源文件哈希。

## 分区与结构

工作板框110×80mm、四层、名义1.6mm，R2圆角；四个M3孔位为(4,4)、(106,4)、(4,76)、(106,76)mm。尺寸为当前工程方案，不是用户新增确认。底座/盖板共用相同孔位和PCB原点，源参数见`hardware/design/mechanical/parameters.json`。

- 后侧：USB-C、CC识别及输入保护；外部供电端子和手动来源开关。
- 中部：HPM5301及晶振/去耦；右上为3.3V、VIO和目标电源，电感及输入/输出电容靠近相应芯片。
- 前侧：ARM20、UART A、UART B和独立DUT供电。两组串口的转换器/去耦成组放置；FSA靠近接口侧。复位及Vref隔离仍保留。
- Vref的U901靠近接口，R53/R54/C61靠近MCU ADC；采样网络与开关电源分区。布局本身不证明140nA指标。
- 四个螺柱周围半径3.75mm为四层铜箔、走线和过孔禁布区；安装孔及其机械封装保留。插头插拔、拨杆操作和线缆弯曲仍需实物确认。

## 手工布线与规则

已撤销原宽范围自动布线试跑的结果，未导入其SES。本轮保留的走线为明确坐标和网络的手工路径。USB、电源、晶振、调试、双串口和模拟检测不得交给全板自动布线；若后续使用自动布线，只能显式选择普通低速Control网络，并重新做完整DRC和关键回路审查。

当前已手工连接：USB D+/D−及ESD路径，USB输入保护/5V主干，U501/L4/C39/C40/C41/C42/U503局部电源，外部/来源/DUT干线，K601 NC放电路径，U401局部开关电源，U502局部反馈/去耦，12颗转换器的本地去耦及ADC分压/滤波局部连线。清单不表示上述模块全部引脚已经布完。

- F.Cu/B.Cu用于信号及电源；In1.Cu、In2.Cu保留GND参考铜面，自定义规则禁止内层走线。通孔焊盘/过孔的反焊盘仍会占用参考面，不能把“禁止内层走线”称为绝对完整平面。
- 全局最小间距/线宽0.127mm；普通通孔过孔0.60/0.30mm，最小孔径0.30mm；铜到板边0.25mm。细间距封装逃线和厂家DFM仍需复核。
- `EXT_INPUT`、`SOURCE_POWER`、`DUT_OUT`干线自定义最小线宽1.2mm，当前主段采用1.5mm；USB_5V主干1.2mm。芯片引脚局部收窄按实际焊盘安排，不能仅凭主段宽度保证整条路径1A/2A。
- Debug/UART/Analog/SwitchPower/Crystal等分类已保存；分类不是布线验收。
- 密集处部分被动件位号隐藏于顶层丝印，以免压焊盘；所有封装保留装配层位号。接口针序、供电极性和保持USB供电的使用限制已标注。拨杆INT/EXT实际方向仍需样品导通核对，当前仅标来源选择名称。

## USB 专项

原试跑存在D+两次换层、D−不换层的不对称路径。现两条信号均为F.Cu、0个信号过孔；ESD直接置于信号路径，短接地支路设地过孔。

USB-C两种插向分别计算至MCU焊盘中心，计入重复焊盘分支。2026-11-13复查发现一种插向长度差约1.88mm，已在接口/ESD短区调整D−路径，主干保持不变：

|插向焊盘|D+路径|D−路径|差值|
|---|---:|---:|---:|
|A6/A7|29.424mm|29.428mm|约0.004mm|
|B6/B7|26.714mm|26.714mm|小于0.001mm|

这是以铜线中心线和焊盘中心定义的几何结果，微米级显示值不代表实际电气精度。两网全程F.Cu、零信号过孔；20mm平行主段线宽0.2474mm、边缘间距0.1524mm，按下述JLC04161H-7628非共面90Ω方案选择。连接器及MCU细间距焊盘仍有0.127mm短出口和不耦合区，不能把这些区域声称为恒定90Ω。主段规则改为按两端Y差筛选，避免整板平移或长线跨越范围使旧位置条件失效；不依赖USB_DP/USB_DM名称自动识别差分对。

以不大于0.1mm间隔检查两条信号中心线下方In1.Cu，638个取样点均落在GND填充铜中。这是几何覆盖检查，不是回流场、阻抗或眼图仿真。最终全板走线后重查参考铜、相邻铜和短分支，并核对制造公差及包含连接器/ESD/封装的实测信号完整性。参考[KiCad自定义规则](https://docs.kicad.org/10.0/en/pcbnew/pcbnew.html#custom-design-rules)、[TI USB布局指南](https://www.ti.com/lit/an/spraar7j/spraar7j.pdf)。
