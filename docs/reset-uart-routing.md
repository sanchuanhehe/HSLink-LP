# 复位与双串口布线检查点

2026-11-13，基于 `6670e83`。本阶段未连接由146降至113项；整板仍未完成，不是投板稿。40MHz、持续1A、140nA/20～30°C及逐板校准后VIO±1%仍待实板验收。

## 已完成的铜连接

|范围|本轮落地|仍未完成|
|---|---|---|
|目标复位|Q701/R51→U804的F_NRST，Q702/R52→U804的F_NTRST；U804→ARM20第15针nRESET、第3针nTRST|NTRST_DRIVE主控到驱动级、RESET_ON跨模块使能|
|双串口目标链路|各4路转换器→FSA的TX/RX/DTR/RTS，FSA→J803/J804对应4个信号针|主控/扩展器到转换器的跨模块连接|
|输入偏置|R705/R709及R707/R708/R711/R712到各转换器输入|所属网络的主控或扩展器源端|
|FSA局部控制|U801、U802、U803各自两只使能脚在F.Cu短接为原同名网络|DEBUG_ON、UART_A_ON、UART_B_ON至逻辑控制器的连接|

路径均由明确坐标的pcbnew原生对象写入，写入前检查异网铜间距，随后由KiCad CLI重新加载工程、重铺铜并完整DRC。控制线路没有被接到常高电源，原FSA断开功能及测量锁的逻辑边界保持；尚不能称接口可工作。复位与UART不是新增的40MHz验收结果。

## 布局、供电与回流

- C59从(35.5,64.8)mm/180°移到(43.0,64.8)mm/0°，为U804的复位信号出口留出空间；保留原网络与元件，调整其P3V6_SW接入和地返回。U804电源换层孔(38.8,65.0)mm在器件体下、非焊盘内，原生API显示双面盖油；阻焊覆盖、焊接及去耦动态效果仍需制造和实板检查。
- U801原(27.3,65.0)mm电源过孔删除，C56电源焊盘改用顶层短线直接连U801.14。这替代上一检查点的底层绕接，为局部使能线留出空间。其信号数据/时钟铜连接保持。
- UART A TX跨过中部线路时，将P3V3在x48.5～51mm的短段改为0.60mm宽的顶层跨接，使用0.60/0.30mm电源孔；没有再增加NRST_DRIVE的过孔预算，也未修改`.kicad_pro`或`.kicad_dru`。
- 另加19个0.60/0.30mm地回流孔，并整理C59、U802/U803的局部接地出口。本轮新增信号孔至最近地孔中心距离0.903～2.119mm，最远为UART B TX的FSA端；电源孔最大2.187mm。这是几何量，不是回流电感或抗干扰保证。
- U1原交错扇出、33个0.50/0.25mm小信号孔保持；未用0.45/0.20mm。当前408个过孔中，375个为0.60/0.30mm。USB和晶振既有顶层零过孔路径未改。
- ARM20→UART A→UART B→DUT电源顺序，以及USB、来源开关、测试点、安装孔位置未变；结构C开放底座与可拆透明盖保持。只有C59移动，最终3D装配仍须以完成的PCB重新导出。

目标侧没有新增测试支线、上拉或常接仪器。本次地孔/阻焊与目标侧铜之间的污染和表面漏电仍须计入140nA整夹具验收；地孔数量和DRC通过不能关闭漏电问题。

## 检查证据与限制

与6670e83比较，759个原焊盘对象的位号、引脚号、UUID及网络分组全部保持，211个封装保留；当前1218段线、408个过孔。12个网类、142条分配以及全局0.127mm线宽/间距、0.25mm板边、普通0.60/0.30mm通孔约束均未修改，没有新增忽略项。

最终完整DRC：一般违规0、未连接113、原理图parity0。预留使能换层孔一度触发3项悬空孔警告，已删除，待控制路径真正接通时再加入；没有用悬空短线掩盖警告。原理图未改，沿用已完成的ERC，不重复把PCB检查称为电气功能验证。

In1/In2各为一个连通GND填充轮廓、零内层信号线。按≤0.2mm步长抽样本轮新增走线中心：无无法解释的参考铜缺口；同网过孔半径0.61mm和同网PTH包围盒外扩0.2mm内的反焊盘分别计数。此检查不覆盖整条回流电流分布、线宽范围内的全部铜颈或阻抗，不能代替SI分析。

已人工查看实际F.Cu/B.Cu局部、整板顶层及两内层铜图：双串口功能块保持对齐，复位出口与ARM20信号分离，接口顺序不变，未发现本轮新增的丝印压焊盘。全板丝印、制造装配、探针/排线空间仍需最终复查。
