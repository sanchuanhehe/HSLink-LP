# USB 控制与 I²C 布线检查点

2026-11-13，基于7437510。未连接113→90项，整板尚未完成，不是投板稿。

## 本阶段落地

- USB-C的CC1/CC2、VBUSD检测及CC_INTn的本地上拉和主控连接完成；USB D+/D−、晶振、40MHz SWD/JTAG及SWDIO DIR的既有铜路径保持不变。
- U102的ILIM档位电阻、Q101/Q102、dVdt电容及FAULTn本地上拉接通。USB_TIER1/2到U201、FAULTn到其他器件仍待布线。
- 主控、USB-C控制器、U201扩展器和U504 DAC的I²C连通；TPS63810的I²C支路尚待接入，不能称整条总线完成。
- C25仅向右移0.2mm至板内坐标(56.2,7.3)mm，整理U102输出局部走线。USB_5V仍有两颗0.60/0.30mm换层孔，其中一颗移动到(56.0,8.95)mm；没有把双孔输出路径缩为单孔。局部引脚/焊盘收窄不构成整条供电热性能的保证。

走线由明确坐标通过pcbnew原生对象写入，写入前检查异网铜间距，随后KiCad CLI重新加载、填铜和完整DRC。原理图、BOM及接口协议未变。

## 换层与参考面

U1北侧新增三颗0.50/0.25mm的I²C/中断换层孔，继续使用区域限定的U1Signal规则；全板现有36颗该规格小信号孔，420颗0.60/0.30mm孔，没有0.45/0.20mm孔。电源、地、热及回流孔规格保持。全局制造约束、12个网类、142条分配和自定义规则文件均未修改。

新增13颗地回流孔，并移动U101原地出口。新增信号/电源孔至最近地孔的中心距离0.7433～3.1604mm；最大为低速I²C上拉处，U1新增孔最大2.4759mm。受现有铜走向限制，未在密集扇出间强插地孔。这些距离和地铜覆盖仅为几何检查，不代表回流电感或抗干扰保证。

初次DAC支路布线出现两对孔间地铜过窄（两内层共4项connection_width违规），已拉开孔距，保留原有最小地连接宽度规则，未新增忽略项。最终In1/In2各为一个连通GND填充轮廓，零内层信号线；≤0.2mm步长检查本轮新增走线中心，除同网过孔/PTH反焊盘之外没有未解释的参考铜缺口。此抽样不是整板SI或回流场验证。

CC的两颗换层孔位于USB连接器体下、非焊盘内；U201的SCL短线利用无裸露焊盘的器件体下空间。原生API显示新过孔双面盖油；连接器底部绝缘、阻焊覆盖与可制造性仍须最终DFM/实物核对。没有在USB数据对上增加过孔。
