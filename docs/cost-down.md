更新：2026-11-07。用户确认优先降本，接受机械继电器声音和毫秒级动作。源文件仅维护 `hardware/design/`，历史以 Git 提交定位。本次为电路审阅稿，不是硬件验收结果。

本轮 JLC 电感、CC、3.6 V 与通用器件换料及计算见 [设计检查](jlc-design-review.md)，最新金额见 [成本](cost.md)。下表记录此前已经实施的拓扑精简，本轮不重复计算收益。

## VIO 电源

U402 TPS7A2036PDBVR 的 3.6 V 辅助轨同时给 FSA2466 和 U502 LDO 供电。U504 使用仍在产的 **MCP4726A0T-E/CH**，VDD=3.3 V；第 6 脚是 VREF，接地并选择内部 VDD 作为参考，不再是旧 DAC 的地址选择脚。A0 订货版本固定 7 位地址 **0x60**，与 0x75 的 TPS63810 不冲突。

删除 U202 TCA9543A、R19～R22、C27，两条旧电源支路并入 I2C_SCL/SDA；保留 R17/R18 两颗 4.7k 上拉至 3.3 V。当前总线地址：WUSB3801=0x68（CTRL 接 P3V3）、MCP4726A0=0x60、TCA9539=0x74（A1/A0 接地）、TPS63810=0x75。所有器件的总线接口均在 USB 辅助供电域，不经过目标板或外部电流测量路径。

总线建议先以 100 kHz 联调。按 `tr≈0.8473×Rpullup×Cbus`，4.7k、100 kHz 的 1000 ns 上升时间对应约 251 pF，400 kHz 的 300 ns 对应约 75 pF；这是估算上限，不是已测电容，实际还需电阻容差、引脚/走线电容及低电平灌电流余量。去掉多路器后任一器件拉死总线会影响整条总线，固件须有超时/恢复，并通过直接连接 MCU 的 VIO_EN、SIG_ARM_REQ、POWER_REQ 保持安全关闭；不能依赖发生故障的 I2C 扩展器解除故障。

MCP4726 与 MCP4725 的配置命令不可混用。依据 DS22272C 第 51、54 页：保持 VIO_EN=0，使用 Write Volatile Memory 命令设置 VREF1:VREF0=00（VDD）、PD1:PD0=00（正常）、G=0（1x）；写入字节为 `0x40, code >> 4, (code & 0x0f) << 4`，其中 code 为 0～4095。地址参数使用 7 位 0x60。读回易失配置和 12 位 DAC 值一致后，等待电源稳定再允许连接。禁止把 I2C ACK 当作模拟电压已经正确；当前无独立 VIO ADC。正常调压不写 EEPROM，不依赖上电召回值。新增独立板型的驱动和错误处理尚未实现。

R58=100k、R59=21.5k、R60=200k，均 0.1%；R58 接 VIO 至 FB，R59 接 FB 至地，R60 将 DAC 输出注入 FB。按 TLV758 的 0.55 V 标称参考：

```
VIO = 0.55 × (1 + 100/21.5 + 100/200) − (100/200) × VDAC
    = 3.3831395 − 0.5 × VDAC
DAC_code = round(4096 × (3.3831395 − VIO_target) / (0.5 × 3.3))
```

软件必须把目标限制到 1.8～3.3 V；VDD、LDO 参考、DAC 失调/增益和电阻误差都会改变实际值，不能用这条标称公式代替校准。100 mA 为首版 VIO 负载预算假设，并非用户确认指标或已验证能力。U502 在 1.8 V / 100 mA 约耗散 0.18 W，U402 另有 USB→3.6 V 损耗，待 PCB 热验证。

R63 默认拉低 VIO_EN。每次启动必须先写 DAC 的易失配置与数据并读回一致，再使能 VIO；不得信任 EEPROM 历史值，也不应在每次调压时写 EEPROM。恢复连接前读取目标 Vref、设置 VIO、等待稳定，先确认 MCU 驱动与 DIR 安全，再允许 FSA 信号开关闭合（12 颗 LVC1 无独立 OE）。当前电路没有独立 VIO 电压反馈 ADC，实际 VIO 精度和启动过冲须在样机上测量；不能把 DAC 应答写成电压已验证。

## 继电器与控制时序

当前仅保留K601 **HFD2/005-S、5V单稳态**：COM接DUT、NO接来源、NC经1k及Q902接地。Vref使用U901 DG2012EDL-T1-GE3；DUT_OUT分压删除。准确引脚、供电/掉电边界和本轮成本见 [优化说明](sense-discharge.md)。

Q601为线圈驱动，Q902为放电NMOS，Q901删除；D601为唯一线圈续流二极管，D901/D902删除。标称5V/167Ω约30mA；ACTIVE与MEASURE均只有K601线圈，Vref检测不再增加约30mA的USB负载。不是目标板电流节省。

|状态|K601|U901采样NO通道|Q902|数字信号|
|---|---|---|---|---|
|OFF|释放|断开|默认关；仅显式放电流程开|全断开|
|ACTIVE|吸合|仅显式检测许可时接通|关|按组显式接通|
|MEASURE|保持吸合|断开|关，NC机械隔离|全断开|
|FAULT/复位|命令释放|断开|默认关|全断开|

继电器接点动作滞后于逻辑电平。硬件互锁只能防止驱动命令同时有效，不能证明触点无重叠；加入续流二极管还会增加释放时间。首版固件预留 **50 ms 切换死区**作为待测初值：供电关断并等待K601释放/抖动稳定后才允许打开Q902；先关Q902并确认栅极稳定后才允许重新供电。50ms不是目标电容放电完成的界限。MEASURE 开始前也应等U901及信号开关关闭、ADC与信号侧稳定。必须实测最坏温度和电源条件，不将 50 ms 写成已验证界限。

MEASURE 仍不能被串口打开、DTR/RTS 或 DAP 命令隐式解除。供电来源与通断仍分离，保留共地，不构成电气隔离仪器。现有固件和 host 尚未实现上述时序及真实 HID 协议。

## 接触、漏电与测量约束

Vref分压仍为68k+68k，1n滤波；检测使能时1.8～3.3V负载约13.24～24.26µA，等效源阻约34k，RC约34µs。只在U901接通NO时加载目标；NC悬空。ADC采样时间、偏置、开关注入与准确度待测。DUT_OUT不再接分压或ADC。K601吸合时NC隔离放电；OFF/USB掉电时NC接R57+Q902，MOS仍有泄漏，不承诺零漏电。

继电器初始接触电阻最大值 100 mΩ 是厂家规定测试条件下的值，不是整条路径保证；仅按该值估算，2 A 时单触点可达 0.2 V 压降、0.4 W 损耗，还未含来源开关、连接器和走线。输出能力、浪涌、寿命与低电流触点稳定性仍需实测。外部仪器的电流限制继续由仪器承担；测量比较时须保持实际 DUT 电压一致。

SW601保留Dailywell 2MD1T1B1M2QES-5及原接线。官方FAQ将SPDT解释为BBM、DPDT为两组SPDT；2M系列Q银触点3A/28VDC阻性额定覆盖5.5V/2A，但准确-5图纸未单列转换时序。资料支持BBM判断，不因缺少专门时序保证而认定会短接。完整料号资料/首板双极转换波形、浪涌仍待确认；助手建议P1改P2，未作为用户确认决策。第二极改上拉/单端接地的建议也未实施。出处与候选接线见[余量与边界说明](electrical-margins.md#来源开关)。先关闭输出再切来源仍是操作要求，不能替代触点验证。

FSA2466 14 个使用通道的 25°C 最大漏电预算已达 140 nA，未计 PCB 和其他支路，新的140 nA整夹具目标仍未闭合；全温表值覆盖20～30°C的保守和为700 nA。继电器绝缘规格也不等于零漏电。FSA掉电保护属首版已接受使用限制，不能写成已解决或已有保护。
