# 供电与检测电路降本

更新：2026-11-07。用户确认优先降本，接受机械继电器声音和毫秒级动作。源文件仅维护 `hardware/design/`，历史以 Git 提交定位。本次为电路审阅稿，不是硬件验收结果。

## 电路替换

| 位置 | 改动 | 保留功能 |
|---|---|---|
| SW601 | NKK → Dailywell 2MD1T1B1M2QES-5 | 手动内／外电源选择，第二极上报来源 |
| U502/U504 | 第二颗 TPS63811 → TLV75801PDBVR + MCP4726A0T-E/CH | USB 侧生成可编程 1.8～3.3 V VIO |
| K601 | TLP3547 → HFD2/005-S 常开触点 | 电脑控制 DUT 电源通断 |
| K901 | ADG4612 的两个检测通道 → HFD2/005-S 双常开触点 | Vref 与目标电压采样整体断开 |
| K902 | ADG4612 的放电通道 → HFD2/005-S 常开触点 | 可控 1k 放电支路 |
| Power | 删除 TPS61040、L3、D1、R40/R41、C37/C38 | 不再需要 12 V 检测开关电源 |

内置目标供电仍由 U501 TPS63811 + U503 TPS22950 负责，1.8～5.0 V／最高 1 A 目标不变；外部路径最高 5.5 V／2 A 目标不变。4 颗 FSA2466 及调试、双 UART、握手和复位信号分组不变。所有继电器驱动均在 USB 侧，外部仪器不承担线圈耗电。

## VIO 电源

U402 的 3.6 V 辅助轨同时给 FSA2466 和 U502 LDO 供电。U504 使用仍在产的 **MCP4726A0T-E/CH**，VDD=3.3 V；第 6 脚是 VREF，接地并选择内部 VDD 作为参考，不再是旧 DAC 的地址选择脚。A0 订货版本固定 7 位地址 **0x60**，与 0x75 的 TPS63811 不冲突。

删除 U202 TCA9543A、R19～R22、C27，两条旧电源支路并入 I2C_SCL/SDA；保留 R17/R18 两颗 4.7k 上拉至 3.3 V。当前总线地址：TUSB320LAI=0x47（ADDR 接地）、MCP4726A0=0x60、TCA9539=0x74（A1/A0 接地）、TPS63811=0x75。所有器件的总线接口均在 USB 辅助供电域，不经过目标板或外部电流测量路径。

总线建议先以 100 kHz 联调。按 `tr≈0.8473×Rpullup×Cbus`，4.7k、100 kHz 的 1000 ns 上升时间对应约 251 pF，400 kHz 的 300 ns 对应约 75 pF；这是估算上限，不是已测电容，实际还需电阻容差、引脚/走线电容及低电平灌电流余量。去掉多路器后任一器件拉死总线会影响整条总线，固件须有超时/恢复，并通过直接连接 MCU 的 VIO_EN、SIG_ARM_REQ、POWER_REQ 保持安全关闭；不能依赖发生故障的 I2C 扩展器解除故障。

MCP4726 与 MCP4725 的配置命令不可混用。依据 DS22272C 第 51、54 页：保持 VIO_EN=0，使用 Write Volatile Memory 命令设置 VREF1:VREF0=00（VDD）、PD1:PD0=00（正常）、G=0（1x）；写入字节为 `0x40, code >> 4, (code & 0x0f) << 4`，其中 code 为 0～4095。地址参数使用 7 位 0x60。读回易失配置和 12 位 DAC 值一致后，等待电源稳定再允许连接。禁止把 I2C ACK 当作模拟电压已经正确；当前无独立 VIO ADC。正常调压不写 EEPROM，不依赖上电召回值。新增独立板型的驱动和错误处理尚未实现。

R58=100k、R59=21.5k、R60=200k，均 0.1%；R58 接 VIO 至 FB，R59 接 FB 至地，R60 将 DAC 输出注入 FB。按 TLV758 的 0.55 V 标称参考：

```
VIO = 0.55 × (1 + 100/21.5 + 100/200) − (100/200) × VDAC
    = 3.3831395 − 0.5 × VDAC
DAC_code = round(4096 × (3.3831395 − VIO_target) / (0.5 × 3.3))
```

软件必须把目标限制到 1.8～3.3 V；VDD、LDO 参考、DAC 失调/增益和电阻误差都会改变实际值，不能用这条标称公式代替校准。100 mA 为首版 VIO 负载预算假设，并非用户确认指标或已验证能力。U502 在 1.8 V / 100 mA 约耗散 0.18 W，U402 另有 USB→3.6 V 损耗，待 PCB 热验证。

R63 默认拉低 VIO_EN。每次启动必须先写 DAC 的易失配置与数据并读回一致，再使能 VIO；不得信任 EEPROM 历史值，也不应在每次调压时写 EEPROM。恢复连接前读取目标 Vref、设置 VIO、等待稳定，再使能电平转换和信号开关。当前电路没有独立 VIO 电压反馈 ADC，实际 VIO 精度和启动过冲须在样机上测量；不能把 DAC 应答写成电压已验证。

## 继电器与控制时序

三颗均采用 **HFD2/005-S、5 V 单稳态**，不用自保持型号。常开触点在 USB 掉电／复位后释放，但有机械延时。K601 使用一极，不通过触点并联宣称更高电流；K901 两极分别断开 DUT_VREF 与 DUT_OUT；K902 一极连接 1k 放电电阻。未使用的触点均标记 NC。

Q601/Q901/Q902 为 AO3400A，栅极受 POWER_SAFE/SENSE_ON/DISCH_ON 控制，各有 100k 下拉；D601/D901/D902 为 1N4148W-7-F，阴极接 USB_5V，阳极接线圈低端。5 V、167 Ω 标称线圈约 30 mA，ACTIVE 通常两颗吸合约 60 mA、MEASURE 仅 K601 约 30 mA；需计入 USB 功率、温升和枚举/挂起策略。

| 状态 | K601 供电 | K901 检测 | K902 放电 | 数字信号 |
|---|---|---|---|---|
| OFF | 断开 | 断开 | 默认断开；仅显式放电流程闭合 | 全断开 |
| ACTIVE | 闭合 | 闭合 | 断开 | 经检查后按组连接 |
| MEASURE | 保持闭合 | 断开 | 断开 | 全断开 |
| FAULT/复位 | 命令断开 | 断开 | 默认断开 | 全断开 |

继电器接点动作滞后于逻辑电平。硬件互锁只能防止驱动命令同时有效，不能证明触点无重叠；加入续流二极管还会增加释放时间。首版固件预留 **50 ms 切换死区**作为待测初值：供电关断并等待后才允许放电；先关放电并等待后才允许重新供电。MEASURE 开始前也应等检测触点释放、ADC 与信号侧稳定。必须实测最坏温度和电源条件，不将 50 ms 写成已验证界限。

MEASURE 仍不能被串口打开、DTR/RTS 或 DAP 命令隐式解除。供电来源与通断仍分离，保留共地，不构成电气隔离仪器。现有固件和 host 尚未实现上述时序及真实 HID 协议。

## 接触、漏电与测量约束

HFD2 的最小切换负载 10 mV / 10 µA 是厂家参考值。检测分压改为 68k + 68k，在 1.8 V 时约 13.2 µA；ADC 等效源阻约 34k，1n 电容的标称 RC 约 34 µs，必须配合 HPM ADC 采样时间、输入漏电及完整误差测量。分压只在 K901 闭合时加载目标，MEASURE 两个检测支路均物理断开。

继电器初始接触电阻最大值 100 mΩ 是厂家规定测试条件下的值，不是整条路径保证；仅按该值估算，2 A 时单触点可达 0.2 V 压降、0.4 W 损耗，还未含来源开关、连接器和走线。输出能力、浪涌、寿命与低电流触点稳定性仍需实测。外部仪器的电流限制继续由仪器承担；测量比较时须保持实际 DUT 电压一致。

SW601 的 3 A / 28 VDC 依据为 Dailywell 2M 系列 Q 银触点资料，精确 -5 后缀仅有尺寸和 AC 额定图。**先断后接（BBM）及准确后缀 DC 额定值须供应商书面确认后才能冻结。** 运行要求先关输出再切来源，但关闭 K601 并不能阻止开关若为 MBB 时把两路上游电源短接；在 BBM 未确认前不允许两路电源同时带电切换，不能把软件提示当作硬件证明。

FSA2466 14 个使用通道的 25°C 最大漏电预算已达 140 nA，未计 PCB 和其他支路，原 100 nA 整板目标仍未闭合。继电器绝缘规格也不等于整板零漏电。数字开关的 USB 掉电反灌工况仍未解决。
