# HSLink-LP 降本原理图审阅稿

打开 `HSLink-LP.kicad_pro`。唯一工作区基于固定 HSLink Pro 1.2.0 原图增改，参考仓库未修改；版本通过 Git 回溯。当前没有 PCB、生产文件或硬件验收结果。

## 本次设计

- SW601 换为 Dailywell 2MD1T1B1M2QES-5；保留手动来源选择与第二极状态输入。
- VIO 改为 TLV75801 + MCP4726，删除第二套 TPS63811 与电感；主目标可调供电保持 TPS63811 + TPS22950。
- K601/K901/K902 三颗 HFD2/005-S 分别用于输出、双路检测和放电；驱动从 USB 侧取电。
- 删除 ADG4612 及其 12 V 升压电路；数字信号仍为四颗 FSA2466。
- 删除不再需要的 TCA9543A 及支路上拉，四个不同地址的 I2C 从设备直接共享总线；VIO DAC 使用 MCP4726A0T-E/CH。
- 候选 BOM 约 ¥254.78／板，十套物料 ¥2,547.80；详见 [成本](../../docs/cost.md)、[电路说明](../../docs/cost-down.md)和[物理引脚表](../../docs/costdown-pinmap.md)。

新增供电、检测页按功能重新分组，器件位号／数值置于主体外，全局标签接短支线，检查两种字体下的实际图面。主控、晶振、启动／复位、主控电源与去耦仍沿用上游布局；34 个符号单元（33 个物理位号）位置和旋转与已记录的上游映射一致。

## 文件验证

2026-11-07：KiCad ERC **0 错误、0 告警**，未增加忽略项。实际 XML 网表与布线前定义的意图比较：168 个物理位号、123 个网络、612 个连接引脚均匹配；44 个 NC 引脚保持独立。核对全部器件显示值、符号、封装及引脚数；BOM 位号、数量和金额一致。

本轮导出九页默认字体及 Arial Unicode MS PDF，查看修改的 Control 和 TargetPower 页，并放大核对 DAC、I2C 标签、位号与数值；其余七页源文件与 Git `3c6e764` 的已检查版本逐字节一致。本次没有沿用旧版“255 标签／零几何候选”统计作为新结果。当前证据、文件哈希及各软件状态见 [validation.json](../validation.json)。PDF、网表、ERC 和封装回读证据位于 Git 忽略的 `reports/`。

MCP 处理器件、连接、库和字段；标准服务缺少的自由文字编辑和孤立 NC 删除通过一次性 MCP 工具完成。注释编辑检查所有电气对象逐字节不变，NC 按 ERC 坐标与 UUID 锁定后仅删除该标记，所有其他对象不变。临时客户端、脚本、扩展和全局验证库均在完成后清理；已安装标准 MCP 服务未修改。

## 尚未完成

- U501 和 L4 尚未绑定封装；原有 MCU、FSA、连接器等仍须完整物理映射与 PCB/DFM 审查。
- 来源开关准确后缀的 BBM、DC 额定值须供应商确认，不能用关闭输出代替来源间防短接验证。
- 继电器的微小电流可靠性、压降、2 A 温升、浪涌、寿命及含续流二极管的释放时序待测。
- 100 nA 附加电流目标尚未闭合；FSA 14 路最大漏电预算已达 140 nA，USB 掉电反灌工况仍未解决。
- VIO 电流预算、精度、启动过冲及热设计待测；40 MHz 和输出能力也不是已实现能力。
- 独立板型、双 CDC、真实 HID、DAC 时序及 MEASURE 锁定尚未实现。

MEASURE 保持目标供电，同时断开调试、复位、双 UART 握手、Vref、采样与放电支路；默认保持共地。ERC 通过不等于允许投板。
