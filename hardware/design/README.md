# HSLink-LP 降本原理图审阅稿

打开 `HSLink-LP.kicad_pro`。唯一工作区基于固定 HSLink Pro 1.2.0 原图增改，参考仓库未修改；版本通过 Git 回溯。当前没有 PCB、生产文件或硬件验收结果。

## 本次设计

- SW601 换为 Dailywell 2MD1T1B1M2QES-5；保留手动来源选择与第二极状态输入。
- VIO 改为 TLV75801 + MCP4726，删除第二套 TPS63811 与电感；主目标可调供电保持 TPS63811 + TPS22950。
- K601/K901/K902 三颗 HFD2/005-S 分别用于输出、双路检测和放电；驱动从 USB 侧取电。
- 删除 ADG4612 及其 12 V 升压电路；数字信号仍为四颗 FSA2466。
- 删除不再需要的 TCA9543A 及支路上拉，四个不同地址的 I2C 从设备直接共享总线；VIO DAC 使用 MCP4726A0T-E/CH。
- 本轮换用 Sunlord 三颗电感、WUSB3801、TPS7A2036、1206 输出电容及准确连接器；见 [JLC 设计检查](../../docs/jlc-design-review.md)与[物理引脚表](../../docs/jlc-pinmap.md)。
- 全部 200 位号已核齐；现货有价部分 ¥112.6726/板，仍缺 11 位号有效报价，不是整板总价。见 [成本](../../docs/cost.md)。
- 按用户确认采用 12 颗 SN74LVC1T45DBVR，SOT-23-6；24 颗去耦、13 颗偏置，删除旧 OE 与未用通道。40 MHz 保持待实测，见 [实施说明](../../docs/level-translation.md)。

新增供电、检测页按功能重新分组，器件位号／数值置于主体外，全局标签接短支线，检查两种字体下的实际图面。主控、晶振、启动／复位、主控电源与去耦仍沿用上游布局；34 个符号单元（33 个物理位号）位置和旋转与已记录的上游映射一致。

## 文件验证

2026-11-07：本次 MCP 检查 ERC **0 错误、0 告警**，未增加忽略项。独立设计意图与实际网表比较：200 个物理位号、119 个连接网络、683 个连接引脚、42 个独立 NC；器件值、符号和封装匹配。除明确替换/删除的器件外，原有引脚网络全部保持；两个开漏复位电路仅重新排版。

12 路按 [电平转换映射](../../docs/level-translation.md)重分配，删除 XLAT_OEn、SWD_UNUSED_A/B、TDO_UNUSED_B 四个网络。FSA、VIO 电源、接口、检测/放电与输出供电电路保持。PDF 共九页，改动的 LogicTranslation（A3）和 Safety 页已实际查看两种字体；其余七页源文件未改。摘要及哈希见 [validation.json](../validation.json)，本轮证据放在忽略的 `reports/lvc12-2026-11-07/`。

器件、连接、库和字段通过已安装 MCP 修改。标准工具对项目库封装临时放置/回读和自由文字编辑的支持缺口由一次性 MCP 适配器补齐；客户端、适配器和缓存用后删除，常驻 MCP 服务未修改。

## 尚未完成

- U501 尚未绑定封装；L4 已绑定更大的 MWSA0603S 封装；原有 MCU、FSA、连接器等仍须完整物理映射与 PCB/DFM 审查。
- 来源开关准确后缀的 BBM、DC 额定值须供应商确认，不能用关闭输出代替来源间防短接验证。
- 继电器的微小电流可靠性、压降、2 A 温升、浪涌、寿命及含续流二极管的释放时序待测。
- 100 nA 附加电流目标尚未闭合；FSA 14 路最大漏电预算已达 140 nA，USB 掉电反灌工况仍未解决。
- VIO 电流预算、精度、启动过冲及热设计待测；40 MHz 和输出能力也不是已实现能力。
- 独立板型、双 CDC、WUSB3801 驱动、真实 HID、DAC 时序及 MEASURE 锁定尚未实现。

MEASURE 保持目标供电，同时断开调试、复位、双 UART 握手、Vref、采样与放电支路；默认保持共地。ERC 通过不等于允许投板。
