# HSLink-LP 降本原理图审阅稿

打开 `HSLink-LP.kicad_pro`。唯一工作区基于固定 HSLink Pro 1.2.0 原图增改，参考仓库未修改；版本通过 Git 回溯。当前没有 PCB、生产文件或硬件验收结果。

## 本次设计

- SW601 换为 Dailywell 2MD1T1B1M2QES-5；保留手动来源选择与第二极状态输入。
- VIO 改为 TLV75801 + MCP4726，删除第二套 TPS63811 与电感；主目标可调供电现用 TPS63810YFFR + TPS22950CDDCR。
- 仅保留K601一颗HFD2/005-S：COM接DUT、NO接来源、NC经1k及Q902放电。Vref采用DG2012EDL-T1-GE3，删除K901/Q901/D901和DUT_OUT分压/ADC连接；开关由USB供电。见[优化说明](../../docs/sense-discharge.md)。
- 删除 ADG4612 及其 12 V 升压电路；数字信号仍为四颗 FSA2466。
- 删除不再需要的 TCA9543A 及支路上拉，四个不同地址的 I2C 从设备直接共享总线；VIO DAC 使用 MCP4726A0T-E/CH。
- 本轮换用 Sunlord 三颗电感、WUSB3801、TPS7A2036、1206 输出电容及准确连接器；见 [JLC 设计检查](../../docs/jlc-design-review.md)与[物理引脚表](../../docs/jlc-pinmap.md)。
- 全部194个板上位号（193采购件+1测试焊盘）已核齐，板上材料¥124.5295/板；加配套排线¥128.3725/套、10套¥1,283.7250。见[成本](../../docs/cost.md)。
- J801改带键ARM20，nTRST第3针、nRESET第15针，删除J802；VTref/所有目标信号的隔离保留，供电走独立J602。见[接口说明](../../docs/arm20-interface.md)。
- 按用户确认采用 12 颗 SN74LVC1T45DBVR，SOT-23-6；24 颗去耦、13 颗偏置，删除旧 OE 与未用通道。40 MHz 保持待实测，见 [实施说明](../../docs/level-translation.md)。

新增供电、检测页按功能重新分组，器件位号／数值置于主体外，全局标签接短支线，检查两种字体下的实际图面。主控、晶振、启动／复位、主控电源与去耦仍沿用上游布局；34 个符号单元（33 个物理位号）位置和旋转与已记录的上游映射一致。

- 140 nA整夹具目标（20～30°C）未闭合；FSA的25°C上限和已140 nA、全温表值保守和700 nA，另有U901/线束/PCB。USB掉电而目标仍供电的FSA保护不在首版支持范围，连接目标信号期间须保持USB供电。
